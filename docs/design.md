# NAGI デザイン方針

参考サイト（[references.md](references.md)）から、NAGIに取り入れる点をまとめた方針。
キーワードは **「静けさ」「余白」「ゆっくり」**。

---

## 1. 色

| 用途 | 値 | 出典 |
|---|---|---|
| 背景（生成り） | `#f7f5f0` | — |
| 本文（柔らかい墨色） | `#3d3d3b` | neie |
| 補足テキスト | `#6e6d69` | neie |
| 線 | `#d9d5ca` | — |
| アクセント（苔） | `#4f5d4b` | — |
| フッターなど暗い面 | `#2f312b` | — |

真っ黒・真っ白は使わない。写真の上の文字だけ白。

## 2. 書体

| 用途 | 書体 | サイズ・太さ |
|---|---|---|
| 見出し・コピー | Shippori Mincho | 見出しは小さく（20〜24px） |
| 英字の見出し・ロゴ | Cormorant Garamond | 見出しは 20〜24px |
| 本文 | Noto Sans JP | **300（細め）**、14〜15px、行間 1.9 |

- **見出しは大きくしない**。余白で目立たせる（neie）
- 明朝体は見出し・コピー・縦書きの文章だけに使う

## 3. 余白とレイアウト

- セクションの間隔：PC 160px／スマホ 96px（neie と同じ）
- **PCでは見出しを左、説明文を右**の2列に分ける（neie）
- **整列を少し崩す**：写真を画面の端からはみ出させる、カードの高さをずらす（neie）
- コンセプトの文章は**縦書き**（neie）

## 4. 写真

- 全景だけでなく、湯気・木目・焚き火・水面など**手元に寄った写真**を混ぜる
- **彩度を抑え**、自然光と影を活かしたトーンで統一する
- 写真の上の文字は白にし、黒を20〜30%重ねて読みやすくする

## 5. 動き（アニメーション）

原則：**動きはゆっくり、数は少なく。1ページに大きな演出は1〜2か所まで。**

| 演出 | 出典 | 使う場所 |
|---|---|---|
| 写真が生成りに溶けていく | ZINEN | TOP：メインビジュアル → コンセプト |
| 日付・時刻の表示 | ZINEN | TOP：メインビジュアルの下 |
| 写真が画面に止まり、上を文章が流れ、次の面に覆われる | shinpaku | TOP：予約への入口／STAY DETAIL：メインビジュアル |
| 文章が止まり、周りを写真が流れる | ZINEN | CONCEPT：「凪」に込めた思い |
| 場面が下から上へめくれる（PCだけ） | ZINEN | CONCEPT：4つの過ごし方 |
| 写真のゆっくりズーム | ZINEN | STAY DETAIL：メインビジュアル、ギャラリー |
| 要素がふわっと現れる | — | 全ページ（控えめに） |

- アニメーションの時間は 1秒以上を基本にし、速い動きは使わない
- **動きを減らす設定（prefers-reduced-motion）の人には、すべての演出を止める**
- 外部ライブラリは使わず、CSSと少しのJSで作る
