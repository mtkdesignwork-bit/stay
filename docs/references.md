# 参考サイト

確認した参考サイトと、NAGIに取り入れる点の記録。最後にデザイン方針としてまとめる。

## 1. neie（ネイエ）

- URL：https://neie.jp/
- 業種：注文住宅（名古屋）
- 良いと感じた点：写真の見せ方、余白、フォント、フォントの位置

### 写真の見せ方
- **メインビジュアルは文字をほぼ載せない**：画面いっぱいの写真に、小さなロゴと短い文章が添えてあるだけ。写真そのものに語らせている
- **寄りの写真を使う**：建物の全景ではなく、水鉢の草花や急須など、手元の小さなものに寄って背景を大きくぼかしている。静けさや空気感が伝わる
- **写真の色調が揃っている**：彩度を抑え、自然光と深い影を活かしたトーンで全体が統一されている
- **画面の端まで写真を広げる**：施工事例は画面の左右いっぱいに、幅の違う写真を隙間なく横に並べている
- **整列を少し崩した配置**：大きな写真は画面の左端に寄せてはみ出させ、文章は右側の中ほど、小さな写真は右下に。きっちり揃えないことで、雑誌のようなリズムが生まれている

### 余白
- セクションの間隔は **PCで160px**（どのセクションも同じ）
- 背景：`#F2F1E9`（生成り）、本文：`#3D3D3B`（真っ黒ではない墨色）、補足：`#6E6D69`
- 文字が小さいぶん、周りの余白がより広く感じられる

### フォント
| 用途 | フォント | サイズ・太さ |
|---|---|---|
| 見出し | A1明朝（モリサワ、有料のWebフォント） | **20px**、レギュラー |
| 本文 | A1ゴシック Light | 13〜14px、細め（300）、行間 1.7 |
| 英字の小さなラベル | Inter | 10px |

- **見出しが小さい**：20pxしかない。大きさではなく余白で目立たせている
- 明朝体は見出しと縦書きの文章だけに使い、本文は細いゴシック体で読みやすくしている

### フォントの位置
- **見出しは左、説明文は右**：「施工事例」の見出しを左の列に、説明文を右の列に分けて置いている
- **縦書きの文章**：コンセプトの文章を縦書きにし、広い余白の右側に寄せて何列も並べている（スマホでも縦書きのまま）
- **メインビジュアルの文章は右下に小さく**：中央に大きなキャッチコピーを置かない

### NAGIに取り入れる案
| 項目 | 今のNAGI | 変更案 |
|---|---|---|
| メインビジュアル | 中央に縦書きのキャッチコピー | ロゴを中央に小さく置き、短い文章を右下に。縦書きのコピーはコンセプトのセクションへ移す |
| コンセプト | 中央揃えの横書き3行 | 縦書きにして右側に寄せ、広い余白をとる |
| 見出し | 英字44px＋小さな和文 | 英字を小さくし（20〜24px程度）、余白で目立たせる |
| 見出しと説明文 | 中央揃えの縦積み | PCでは見出しを左、説明文を右に分ける |
| 本文フォント | Noto Sans JP 400 | 細めの300にする。A1ゴシックは有料なので、無料の近い書体で代用 |
| 見出しフォント | Shippori Mincho | そのままでA1明朝に近い。必要なら Zen Old Mincho も候補 |
| 写真 | 同じ大きさを揃えて並べる | 端まで広げる写真と、はみ出させる写真を混ぜる。施設詳細のギャラリーで特に活かす |
| 写真の選び方 | — | 全景だけでなく、湯気・木目・焚き火など手元に寄った写真を混ぜる。彩度を抑えたトーンで統一する |
| 色 | 背景 `#f7f5f0`、文字 `#2b2a27` | 文字を少し柔らかい墨色（`#3d3d3b` 前後）にする |

## 2. 心拍（Shinpaku）

- URL：https://shinpaku.co/
- 業種：農業・宿泊（奈良）
- 良いと感じた点：セクションが切り替わるとき、大きな写真が背景になり、スクロールすると消えていく

### 動きの中身
1. 大きな写真が画面いっぱいに出てきて、画面に**張り付いて止まる**
2. 止まった写真の上を、縦書きの白い文章がスクロールして流れていく。写真には黒の30%を重ねて、文字を読みやすくしている
3. 次のセクション（生成りの背景）が下からせり上がり、写真を**幕のように覆い隠して**消える
4. 写真自体もスクロールに合わせてわずかに動き（パララックス）、奥行きを出している

### 作り方
- 写真を入れた箱を `position: sticky; top: 0; height: 100vh;` にして、セクションの先頭に置く → スクロールしても画面に張り付く
- 文章はその後ろに続けて置き、写真の上に重ねて流す
- 次のセクションに背景色と `position: relative` を付けて、写真より手前に重ねる → 写真が隠れていく
- **基本の動きはCSSだけで作れる**。JSが必要なのは、写真がわずかに動くパララックスの部分だけ（なくても成立する）
- スマホでも同じ仕組みで動く

### NAGIで使えるか
**使える。** CSSの `sticky` だけで実装でき、ページの読み込みも重くならない。静かに場面が切り替わる演出は、NAGIのコンセプトとも合う。

ただし、使いすぎると単調になり、スクロールも長くなる。**1ページに1〜2か所**に絞る。

### NAGIに取り入れる案
| 場所 | 使い方 |
|---|---|
| TOP：メインビジュアル → コンセプト | メインビジュアルの写真が張り付き、生成りのコンセプトのセクションがせり上がって覆う。neieから取り入れる「縦書きのコンセプト」と組み合わせられる |
| TOP：予約への入口 | 夜の焚き火の写真が張り付き、その上を「静けさに、会いにいく。」の文章と予約ボタンが流れていく |
| CONCEPT：何もしない一日 | 時間帯ごとの写真（朝・昼・夕・夜）が張り付いては切り替わり、上をタイムラインの文章が流れる |
| STAY DETAIL：メインビジュアル | 宿の写真が張り付き、宿の紹介文がその上を流れてから本文に入る |

**注意点**
- 写真の上の文字は白にして、黒の重ね（30%前後）で読みやすさを確保する
- 写真の高さは `100vh` ではなく `100lvh` などを使い、スマホでアドレスバーが出たり消えたりしても写真が伸び縮みしないようにする
- 動きを減らす設定にしている人には、パララックスを止める

## 3. ZINEN（NATUREHOOD PROJECT）

- URL：https://naturehood-pj.com/zinen/
- 業種：一棟貸しのサウナ付きリバーサイドヴィラ（福岡・那珂川）。**NAGIと業態・ターゲットが最も近い**
- 良いと感じた点：スクロールで写真が切り替わるなど、アニメーションの使い方

### アニメーションの中身（上から順に）

**① メインビジュアル：動画が闇に溶けていく**
- 背景は川の動画。黒を30%重ねている
- スクロールすると、写真の下側からグラデーションで透けて暗い背景に溶け込み、次のセクションと境目なくつながる（`mask-image` のグラデーションを動かしている）
- 画面下に「福岡県那珂川市｜一棟貸しのサウナ付きリバーサイドヴィラ」と、**今日の日付・時刻・気温**を小さく表示。「今この場所に流れている時間」を感じさせる演出

**② コンセプト：文章は止まり、写真が流れていく**
- 「自然に抱かれ、あるがままに。」の文章が画面に張り付いて止まる（`sticky`）
- その周りを、大きさの違う写真が左右交互に、画面の端からはみ出しながら流れていく
- 写真は枠より120%に拡大しておき、スクロールに合わせて枠の中で少しずつ上下に動く（パララックス）。枠そのものは動かないので上品に見える

**③ Stay / Retreat / Dining / Experience：画面を止めて、4枚の場面がめくれる**
- 画面を固定したまま、4つの場面（宿・サウナ・食事・体験）を重ねておく
- スクロールすると、手前の場面が**下から上へ拭き取られるように消え**（`clip-path: inset()` をスクロール量に合わせて変える）、下の場面が現れる
- 各場面の中では、写真が2秒かけてクロスフェードし、5秒かけてゆっくり拡大から等倍に戻る（ゆっくりズームする効果）
- **この演出はPCだけ**。スマホでは普通に縦に並べている

**④ セクションのつなぎ目**
- 暗い背景と明るい背景の境目に、透明へのグラデーションを重ねて、色が急に切り替わらないようにしている

### 作り方と難しさ
| 演出 | 作り方 | 難しさ |
|---|---|---|
| ① 動画が闇に溶ける | `mask-image` のグラデーション＋スクロールで位置を変える少しのJS | 低〜中 |
| ② 文章が止まり写真が流れる | `sticky`＋写真のパララックス（JS） | 中 |
| ③ 場面がめくれる | 画面を固定（`sticky`）し、スクロール量から `clip-path` を計算するJS | 中〜高 |
| 写真のゆっくりズーム | CSSの `transition` だけ | 低 |

いずれも外部ライブラリなしで作れる。ZINENもGSAPなどは使っておらず、自前のJSで制御している（写真のスライドだけ Splide を使用）。

### NAGIで使えるか
**使える。ただし全部入れると、静けさより「動き」が目立ってしまう。** NAGIでは「動きはゆっくり、数は少なく」を原則にして選ぶ。

| 演出 | 判断 | NAGIでの使い場所 |
|---|---|---|
| ① 闇・生成りに溶ける境目 | **採用** | TOP：メインビジュアル → コンセプト。shinpakuの「幕のように覆う」の代わりに、こちらのほうが「凪」らしく静か |
| ① 日付・時刻・気温の表示 | **採用（簡易版）** | TOP：メインビジュアルの下。気温は架空の宿のため表示せず、日付と時刻だけにする |
| ② 文章が止まり写真が流れる | **採用** | CONCEPT：「凪」に込めた思い。neieの縦書きと組み合わせる |
| ③ 場面がめくれる | **採用（PCだけ）** | CONCEPT：4つの過ごし方（サウナ・星空・焚き火・海）にちょうど4場面で合う。スマホは縦に並べる |
| 写真のゆっくりズーム | **採用** | STAY DETAIL のメインビジュアル、写真ギャラリー |

**注意点**
- 動きを減らす設定にしている人には、①〜③をすべて止めて普通のレイアウトで表示する
- ③はスクロール量が長くなる（ZINENは画面9枚分）。NAGIでは4場面で画面5枚分程度に抑える
- 動画は容量が大きいので、NAGIでは写真で代用する
